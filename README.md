# Devans Co Pty Ltd — Bold Coming Soon

A modern, responsive static landing page. No dependencies, no build required.

## Deploy on Vercel

1. Upload these files to the root of a GitHub repository.
2. In Vercel, choose **Add New > Project** and import the repository.
3. Choose **Other** as the framework preset. No build command or output directory is needed.
4. Deploy, then add `devanscorp.com` in **Project > Settings > Domains**.
5. Update your DNS at your domain registrar using the exact records Vercel specifies. **Keep existing Google Workspace MX, SPF, DKIM, and DMARC records intact** so that company email continues working.

## Files
- `index.html` — content, page structure, SEO
- `styles.css` — design and responsive layouts
- `logo.svg` — editable bold DC logo
- `favicon.svg` — browser icon
- `script.js` — copyright year
- `vercel.json` — deployment settings

## Brand direction
Charcoal background, restrained burgundy/lavender undertones, metallic gold details, strong geometric typography. All imagery is vector/CSS; no large external images needed.
